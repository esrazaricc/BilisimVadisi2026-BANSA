# BANSA V16.4 — Central State Priority + Fast Local Naturalizer

## Conversation-state contract

Current-turn explicit information always wins over historical context:

1. explicit campaign/topic
2. explicit bank
3. explicit finance product/family
4. explicit variant
5. explicit amount/maturity
6. only then inherited conversational slots

A new explicit product clears the previous product, amount, maturity and comparison state. If the new product omits a bank, only one unambiguous recent bank may be inherited. A recent multi-bank comparison is an ambiguity boundary and older single-bank context is not resurrected.

Covered regressions include:
- Türkiye Finans insured vehicle -> `36 ay`
- Albaraka + Türkiye Finans housing comparison -> `500 bin TL 36 ay`
- housing comparison -> `Albaraka Türk eğitim finansmanının avantajları?`
- Albaraka housing -> `Peki eğitim finansmanının avantajları?`
- motorcycle context -> explicit global vehicle comparison
- campaign merchant switch -> preserve only campaign bank

## Fast naturalizer

The deterministic finance/campaign layer remains the sole source of facts. A local Qwen model is allowed only to rewrite broad product/feature answers.

Priority:
1. loopback-only OpenAI-compatible local Qwen endpoint (`BANSA_LOCAL_LLM_BASE_URL`)
2. bundled local-only `Qwen/Qwen3-0.6B` naturalizer
3. compact deterministic prose fallback

The surface verifier rejects generated output when it:
- introduces a numeric value absent from the deterministic answer,
- introduces another bank,
- introduces unsupported marketing claims,
- leaks internal terms such as UNVERIFIED / exact / snapshot / RAG / evidence,
- contains a URL generated by the model.

Official source links are never generated by the LLM; they are appended from the deterministic answer after verification.

## Configuration

```env
BANSA_FAST_NATURALIZER_ENABLED=1
BANSA_FAST_NATURALIZER_TIMEOUT_SECONDS=8
BANSA_LOCAL_LLM_BASE_URL=http://127.0.0.1:8000/v1
BANSA_LOCAL_LLM_MODEL=Qwen/Qwen3-30B-A3B-Instruct-2507
```

The local endpoint client rejects non-loopback URLs. External/commercial LLM APIs are not part of this path.
